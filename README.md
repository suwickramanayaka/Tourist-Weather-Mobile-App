# SwiftUI Weather Application

A **Tourist Utility App** built using **SwiftUI**, providing real-time weather updates, air quality data, and top tourist attractions on an interactive map. This project demonstrates the integration of modern native development practices, leveraging **CoreLocation**, **MapKit**, and **SwiftData**.

## Features

- **Real-Time Weather and Air Quality Data**
  - Fetch data from [OpenWeatherMap API](https://openweathermap.org/api).
  - Asynchronous API calls using `async/await`.
  
- **Tourist Attractions**
  - View top 5 tourist places for any location using **MapKit**.
  - Interactive map with pins and detailed descriptions.

- **Persistent Storage**
  - Save and manage visited locations with **CoreLocation** and **SwiftData**.
  - Swipe to delete stored locations.

- **Intuitive User Interface**
  - Fully responsive UI adhering to Apple’s design guidelines.
  - Seamless navigation across different tabs.

## Functional Tabs

1. **Now**: Displays real-time weather and air quality details.
2. **5-Day Weather**: Hourly and daily weather forecasts with rich visuals.
3. **Place Map**: Interactive map with top tourist attractions.
4. **Stored Places**: A list of saved locations with delete functionality.

## Development Guidelines

- **Languages**: Swift 5.7+.
- **Frameworks**: SwiftUI, CoreLocation, MapKit.
- **API Usage**: OpenWeatherMap API (up to 1000 free calls/day).
